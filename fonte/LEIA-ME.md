# Fonte

Copias geradas pelo `build.py` a cada publicacao, para que nada viva so fora
do controle de versao. **Nao edite nada aqui**: os originais ficam na raiz do
projeto, um nivel acima de `site/`.

- `caderno.html` - a fonte unica do app. Gera o `site/index.html`.
- `build.py` - o gerador.
- `CLAUDE.md` - como mexer no projeto.
